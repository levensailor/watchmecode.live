SQL lab

Drop CSV files into the session and they become tables. The candidate writes .sql files, presses Run, and gets formatted result tables, with the full schema printed on every run.

  • Seed data per assessment
  • Works for analyst, data, and backend roles
  • Results in the playback, like any other run

React lab

Components render in the sandboxed preview as you type, with React loaded from a CDN and htm templates instead of a build step.

  • Live refresh on every edit
  • Console output from the preview
  • Swap in any npm package by URL

Prompt engineering lab

Hiring for AI-assisted engineering? Give candidates a realistic brief and have them write the prompt they'd hand to a coding agent. Press Run and an AI reviewer, powered by Vercel AI Gateway, role-plays that agent.

  • A mock run: what an agent would actually build from that prompt alone
  • Scores for intent, guardrails, and context (MCP servers, integrations, files, credentials)
  • The assumptions an agent would make and might get wrong, plus the questions it should ask
  • Every review is saved with the session, so you can see how the prompt improved

System design whiteboard

A shared Excalidraw board, saved with the session as a file. Draw the architecture together, then review it in the portal.

  • Hand-drawn style that keeps it informal
  • Saved and synced like code
  • Pairs with a notes file for trade-offs

Sandbox labs cost 2 credits

Labs that run in a full microVM (the sandbox runner, and project and API labs) use 2 interview credits because they reserve dedicated compute. Browser labs (SQL, React, whiteboard) cost the same 1 credit as any interview.
